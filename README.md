# עורך העיצוב של דן חריטה

עורך שמאפשר ללקוח לעצב את החריטה בעצמו על דף המוצר באתר (מבוסס 2all),
לראות את התוצאה על תמונת המוצר, ולייצר תמונת אישור + קובץ DXF לחריטה.
מוגש דרך GitHub Pages מהתיקייה הזאת.

## התקנה
שורה אחת בסוף "תוכן שמאל לדף מוצר" (התבנית הגלובלית של דף המוצר):

    <script src="https://danharita.github.io/custom-fonts/editor/loader.js" async></script>

זהו. אין צורך לגעת בזה שוב — עדכונים לעורך מגיעים אוטומטית.

## איך זה עובד
- `loader.js` — טוען קטן. מזהה בגלריה תמונות ששמן מתחיל ב-`engrave-bg-`,
  מסתיר אותן מהגלריה, ומציג ללקוח בחירה: "עיצוב לבד" / "עצבו בשבילי".
  מסתיר תמיד את השדה "קישור לעיצוב". טוען את `editor.js` רק בלחיצה על "עיצוב לבד".
- `editor.js` — העורך המלא (מנוע + סמלים + ממשק). נבנה מקוד המקור שב-`src/`.

## מצב בדיקה (פיילוט)
כרגע העורך מופיע רק במצב בדיקה, כדי שלקוחות עדיין לא יראו אותו.
- להפעיל: לפתוח את דף המוצר עם `#dhtest` בסוף הכתובת.
- לכבות: `#dhtest-off`.
- ההפעלה נשמרת בדפדפן, אז אחרי פעם אחת זה נשאר דלוק בו.
כשמוכנים להשקה: לשנות `LIVE` ל-`true` ב-`src/loader.js` ולבנות מחדש.

## תמונות רקע למוצר
בכל מוצר מעלים תמונות (צילום ישר מלמעלה) עם שם שמתחיל ב-`engrave-bg-`,
וסיומת מספר שקובעת את הסדר:
- `engrave-bg-<בסיס>-1` = המשטח הראשון, `-2` = השני, וכן הלאה.
- מעלים תמיד באותו סדר.

## הגדרת מוצר (בקוד)
ב-`src/editor-app.js`:
- `SURFACES_LIB` — סוגי משטחים (קרש, סכין): גודל אזור החריטה במ"מ, מגבלות,
  שמות שדות הטקסט במערכת, צבע החריטה בתצוגה.
- `PRODUCTS` — לכל בסיס-שם, רשימת המשטחים לפי הסדר. אפשר לקבע מיקום מסגרת
  לכל צילום: `{ lib: 'board', area: { xPct, yPct, wPct, hPct, shape } }`.
  בלי `area`, המסגרת ממורכזת אוטומטית בפרופורציה הנכונה.

המוצר בפיילוט (2851248) מוגדר תחת הבסיס `test`: תמונה 1 = קרש, 2 = סכין,
עם מיקומי מסגרת שנמדדו על הצילומים האמיתיים.

## בנייה
הקבצים `editor.js` ו-`loader.js` נוצרים — לא לערוך ידנית. לבנות:

    cd editor/src && node build.js

בדיקות (Playwright): `test_mock.py` (זרימה מלאה), `test_desktop.py`, `test_touch_mock.py`.

## מה עוד נשאר (מחוץ לתיקייה הזאת)
- שרת קטן ב-Render לשמירת הקבצים והחזרת קישור להזמנה.
- סנכרון הקבצים למחשב שמחובר ללייזר, לפי מספר הזמנה.
- אופציונלי: כלי ויזואלי לכיוונון מסגרת אזור החריטה למוצרים חדשים.

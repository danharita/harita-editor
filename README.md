# עורך העיצוב של דן חריטה

התיקייה הזאת מגישה את עורך העיצוב לדפי המוצר באתר (דרך GitHub Pages).

- `loader.js`: טוען קטן. נכנס לתבנית "תוכן שמאל לדף מוצר" בשורה אחת:
  `<script src="https://danharita.github.io/custom-fonts/editor/loader.js" async></script>`
  הוא מסתיר מהגלריה תמונות ששמן מתחיל ב-`engrave-bg-`, ומוסיף את הכפתור "רוצה לעצב לבד".
- `editor.js`: העורך עצמו. נטען רק בלחיצה על הכפתור.

בזמן הפיילוט הכפתור מופיע רק במצב בדיקה: פותחים את דף המוצר עם `#dhtest` בסוף הכתובת.
`#dhtest-off` מבטל את מצב הבדיקה בדפדפן הזה.

הקבצים נבנים מקוד המקור של העורך. לא לערוך אותם ידנית.
